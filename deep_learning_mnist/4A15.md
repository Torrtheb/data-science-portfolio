# Part 5: Deep Learning Fundamentals Project

Congratulations on reaching the end of the Deep Learning fundamentals sprint! In this section, you will put the skills that you have learned to test by building a multi-layer perceptron in order to solve classification problems for the MNIST[ dataset](https://www.kaggle.com/competitions/digit-recognizer). Despite the fact that the origin of the problem is more towards computer vision than tabular data, a multi-layer perceptron approach could also give relatively high accuracy here.


## Objectives



1. Find MLP architecture that would work well for a given dataset.
2. Practice using Pytorch and Pytorch Lightning tools.
3. Practice building and customizing neural networks. 

<br>

## Requirements



* Download data from [Kaggle](https://www.kaggle.com/competitions/digit-recognizer)
* Create a 3 partition data split (train 60%, validation 20% and test 20%).
* Create an MLP training pipeline which can be easily customized.
* Make sure to test different optimizers, batch sizes, activation functions, learning rates, dropout ratios, hidden layer architectures, loss functions.
* Evaluate best model performance on test dataset.
* Training should be done on GPU. There are cloud providers that give free GPU usage: [Google Colab](https://colab.research.google.com/) and [Kaggle Notebooks](https://www.kaggle.com/code).
* Make suggestions on how to improve the model further.

<br>

## Evaluation Criteria



* Data cleaning. Was the data properly cleaned: duplicates identified, corruptions omitted?
* Adherence to the requirements. How well did you meet the requirements?
* Algorithm’s classification performance. How robust did your algorithm perform the predictions?
* Code quality. Was your code well-structured? Did you use the appropriate levels of abstraction? Did you remove commented out and unused code? Did you adhere to PEP8?
* Code performance. Did you use the suitable algorithms and data structures to solve the problems?

<br>

## Project review

During your project review, you should present your project as if talking to your friend, who is a senior data scientist. Present the techniques that you applied and why you have chosen them. Explain what are the possible areas of improvement.

During a project review, you may get asked questions that test your understanding of covered topics:



* Why do we need activation functions in neural networks?
* How do SGD and Adam optimizers work? What are the main differences between them?
* What is the purpose of dropout layers and weight decay?
* How can the vanishing and exploding gradient problem be mitigated?
* What loss functions could be employed for classification problems? How do they differ?
* What is the main purpose of transfer learning?
* What are the differences between using transfer learning with feature extraction and fine-tuning?
* What options do you have in neural networks when having an imbalanced classification problem?
